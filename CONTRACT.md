## Provider adapter interface (packages/provider-sdk/src/index.ts — Agent 2 owns)
ProviderAdapter { id: string; protocol: 'openai'|'anthropic'; chat(request: NormalizedChatRequest, credential: string, signal: AbortSignal): Promise<NormalizedChatResponse>; chatStream(...): AsyncIterable<string /* SSE-ready chunks */>; listModels(credential): Promise<string[]>; testConnection(credential): Promise<boolean> }
Adapters required: openai, anthropic, gemini, deepseek, moonshot, glm, openrouter, tokens (base https://tokens.bd/v1, OpenAI-compatible), ollama (base http://localhost:11434/v1 default, local only via explicit admin config). All translate to/from normalized form. No adapter may execute client tools.

## Gateway routes (Agent 2 owns apps/api/src/modules/gateway/*)
POST /v1/chat/completions, GET /v1/models, POST /v1/embeddings, POST /v1/responses, POST /v1/messages (Anthropic). Auth: `Authorization: Bearer <router-api-key>` (ApiKey.keyHash lookup) OR session for dashboard test calls. SSE streaming, keep-alive, disconnect/timeout handling, no full buffering of streams. Fallback: only on 429/5xx/timeout/unavailable, respect Retry-After, NEVER retry 401/400, NEVER switch model after first streamed chunk, NEVER double-bill (usage recorded once per request, on final outcome).
